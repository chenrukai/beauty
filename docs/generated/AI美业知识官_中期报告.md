## 二、主要研究内容

本课题主要围绕美业垂直领域知识的统一管理、结构化处理、智能检索与辅助问答展开研究，目标是设计并实现一个基于 CMS 架构思想的“AI美业知识台”系统。系统面向美业门店培训、知识沉淀、产品介绍、护理流程学习等实际场景，重点解决传统资料分散、知识难检索、经验难沉淀、问答缺乏专业依据等问题。

从论文研究内容来看，本课题重点包括以下几个方面。第一，系统总体架构设计。项目采用前后端分离与模块化单体相结合的实现方式，后端使用 Spring Boot 构建业务系统，前端使用 Vue 3 构建交互界面，并结合 MySQL、Redis、RabbitMQ、MinIO、Milvus 等组件形成完整的业务支撑环境。该架构既满足了毕业设计的完整性要求，也保证了系统具有较好的工程实现价值。

第二，内容管理与知识组织研究。系统以 CMS 思想为基础，围绕知识列表、分类树、公告管理、文件上传、任务监控、实体确认、用户管理等模块，实现美业知识内容的统一录入、维护、发布、检索和展示。管理员可以管理知识与分类，普通用户可以浏览知识、查看推荐内容并进入问答功能，从而形成内容管理到内容消费的完整闭环。

第三，多媒体知识处理流水线研究。针对上传的文档资料，系统设计了“文件上传、消息入队、文本提取、知识分块、向量化、状态回写”的异步处理流程，以解决同步处理效率低、处理状态不可追踪和失败难回溯等问题。该流程为系统后续的语义检索和问答生成提供了基础数据支持。

第四，RAG 智能问答研究。系统基于检索增强生成思想，将知识库检索结果与用户问题共同输入大模型，实现对美业问题的智能回答。检索部分采用关键词检索与向量检索结合的混合检索方式，以兼顾专业术语匹配与语义相似召回；回答结果支持来源展示，以增强系统的可信度和可解释性。

第五，知识结构化与实体关系研究。结合美业行业特点，系统初步构建了“成分—功效—产品”的知识关联模型，并设计了实体抽取待确认机制，支持管理员对系统自动识别出的实体进行审核与确认。该部分为后续知识图谱扩展、关联推荐和路径展示提供了结构化基础。

第六，系统可用性与业务展示研究。为了提升系统的完整度和演示效果，本课题还在普通用户端增加了首页推荐、收藏、浏览、来源查看等功能，在管理端增加了运营总览、状态流程、分页展示、中文文案统一、链接跳转等优化内容，使整个系统更贴近实际应用场景。

#### 3. 开学后第1周已完成内容

开学后第1周，主要完成了管理端核心业务模块的初步实现。具体包括分类树管理、知识列表管理、知识新增与编辑、公告管理、文件上传与任务入队、用户登录与角色跳转等功能。同时，对后台页面结构进行了初步划分，形成了内容管理、任务监控和用户管理等主要功能入口。经过联调后，系统已经能够支撑管理员对基础知识内容进行维护。

与此同时，系统已基本实现本地知识库结合大模型的问答流程，包括问题提交、知识召回、回答生成、会话保存和来源展示等功能。对于大模型本地运行、Ollama 接入、模型响应过慢、服务异常等问题也进行了多轮排查与修复，当前系统在可用模型配置下已具备基本问答能力。
